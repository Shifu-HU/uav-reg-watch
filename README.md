# UAV Reg Watch — Drone Regulation Radar

> Drone regulation monitoring for **Windows desktop and Android**. Primary source is the
> CAAC (Civil Aviation Administration of China) official site, with SearXNG / Bing as
> secondary sources. A **local small model** summarises every item, out-of-region rules
> are filtered out automatically, and at least 200 items are surfaced per day.

**[⬇️ Download the installer (Releases)](https://github.com/Shifu-HU/uav-reg-watch/releases/latest)** ｜ [Architecture](docs/architecture.html) ｜ 简体中文：[README.zh-CN.md](README.zh-CN.md)

## ⚠️ Read this first: the summary is an index, the brief and the original are the conclusion

The one-line summary in the app is generated by a local small model. **It exists for fast
scanning only, it can differ from the source text, and it must never be used as a conclusion.**

1. Open **Morning Brief** in the sidebar and read the region / time window / source of every item, plus the "what to do" line;
2. Every entry ends with **View original →**, which opens the official announcement in your system browser. **The original text always wins**;
3. For anything about no-fly zones, penalties or registration, **always verify against the original announcement and local rules**. Never make a flight decision based on the summary.

## 1. Install

Two editions with identical UI and logic — pick one or both.

| | Desktop | Mobile |
|---|---|---|
| UI | Native PySide6 window | WebView shell app (Android) |
| Install | `UAVRegWatch-Setup.exe` | `UAVMobile.apk` |
| AI | Local Ollama on your PC | **Reuses the host PC's Ollama** |
| Design | One shared theme token set (8 colour schemes × dark/light), zero drift | Same |

### 1.1 Desktop

1. Download `UAVRegWatch-Setup.exe` from [Releases](https://github.com/Shifu-HU/uav-reg-watch/releases/latest) and run it (installs to `%LOCALAPPDATA%\UAVRegWatchMine`, no admin rights needed);
2. Launch from the Start menu or the desktop shortcut. The installer ships a **pre-built baseline database**, so the app has content the moment you open it — no first full crawl needed.

> To rebuild the baseline from scratch: delete the `data` folder in the install directory and the app re-crawls everything (slow, one-off).

### 1.2 Mobile (Android / MuMu and similar emulators)

Phones and emulators cannot host Ollama, so all AI runs on the host PC and the device is just a WebView shell. Three steps:

```bash
# 1) start the backend on the host (listens on 8765)
python mobile/server_mobile.py

# 2) reverse-map the port to the device (second MuMu instance is usually 16416)
adb -s 127.0.0.1:16416 reverse tcp:8765 tcp:8765

# 3) install and open the shell app
adb -s 127.0.0.1:16416 install -r UAVMobile.apk
```

> The adb serial differs per device: the first MuMu instance is usually `16384`, the second `16416`; on a real phone use the serial from `adb devices`.
> Alternatively double-click `mobile\start_mobile.bat`, which does steps 2 and 1 for you.

## 2. First-run setup

Only one thing to check: **[Ollama](https://ollama.com) is installed and a model is pulled**.

```bash
ollama pull qwen3:4b
```

The app uses the model `uav-reg` by default and falls back to `qwen3:4b` → `qwen3:8b` when it is missing (see the `llm` section of `config.yaml`). You can switch models any time in Settings.

Everything else has a sensible default:

| Setting | Default | Notes |
|---|---|---|
| Region | Shenzhen / Guangdong | Basis of the geo filter — **change it to your city first** |
| Daily schedule | 07:30 | Automatic incremental crawl at this time |
| Sources | CAAC site + Bing | SearXNG is off until you host one |
| Daily quota | ≥ 200 items | Today's new + unread backlog |

## 3. Daily use

- **Today**: a top summary bar (new today / total / locally relevant) plus three blocks (Major / Watch closely / Older), each sorted Major → Important → Normal;
- **Morning Brief**: flight verdict banner on top (no-fly / caution / clear), then sections (temp no-fly / new today / watch / reference);
- **Favourites**: star and filter, consistent across desktop and mobile;
- **Filtered out**: out-of-region items are archived here, not silently dropped;
- The first Morning Brief takes about 40 seconds (includes a weather lookup); the app pre-warms it at startup, after which it opens instantly.

---

## 4. Settings

Floating-island groups — **every change saves itself, no save button**:

- **Region**: province / city dropdowns, drives the geo filter (keeps national + local + same-province rules);
- **Content filter**: e.g. whether to show industry news;
- **Search & model**: Ollama address and model name;
- **Appearance**: 8 colour schemes × dark/light, applied instantly;
- **My devices**: your drones and weight classes (micro / light / small…), which shape the flight advice.

## 5. FAQ

| Symptom | Cause & fix |
|---|---|
| Morning Brief takes long to open | First generation takes ~40 s (weather lookup included). It is pre-warmed at startup and opens instantly afterwards; while generating the page stays responsive with an elapsed counter |
| Summary disagrees with the original | Expected — the summary is only an index. Read the Morning Brief body, then "View original". For flight decisions the original is authoritative |
| Mobile app cannot connect | Check three things: ① `server_mobile.py` is running on the host; ② `adb reverse tcp:8765 tcp:8765` was executed; ③ the adb serial / emulator port is right (second MuMu instance = 16416) |
| Does the phone need Ollama? | No — and it cannot run it. All AI work happens on the host |
| Start over with clean data | Delete the `data` folder; the baseline is rebuilt on next launch |
| CAAC site returns nothing | The site search only accepts POST (GET redirects to an anti-bot page) — the app handles this; an empty result usually means the site is down for maintenance |
| National rules get filtered as "out of region"? | They don't. The app strips the CAAC footer institution list before judging, and always keeps items with national markers |

## 6. Run from source

Skip the installer, or run on another OS:

```bash
git clone https://github.com/Shifu-HU/uav-reg-watch.git
cd uav-reg-watch
pip install -r requirements.txt

python -m uavwatch.cli doctor        # check environment
python -m uavwatch.cli bootstrap     # first full baseline (slow, one-off)
python -m uavwatch.tui               # desktop GUI
python -m uavwatch.cli daemon        # scheduled daemon (uses config schedule)
python -m uavwatch.cli brief         # generate today's brief manually
python mobile/server_mobile.py       # mobile backend (port 8765)
```

Project layout:

```
uav-reg-watch/
├── src/uavwatch/          shared core for both editions
│   ├── config.py          config load/save
│   ├── storage.py         SQLite storage (WAL)
│   ├── geo.py             geographic filtering (core)
│   ├── fetcher.py         HTTP fetching (rate limit / encoding fallback)
│   ├── llm.py             local model analysis + rule fallback
│   ├── pipeline.py        fetch -> dedup -> analyse -> filter -> store
│   ├── morning.py         brief generation (Markdown / HTML / plain text)
│   ├── theme.py           theme tokens (single source of styling)
│   └── sources/           caac / searxng / bing / local
├── mobile/                mobile edition (backend + UI + one-click script)
└── config.yaml            all configuration
```
