# UAV Reg Watch — Drone Regulation Radar

> Drone regulation monitoring with **two standalone editions**: the mobile edition is a
> single APK that runs entirely on the phone (AI included), and the desktop edition is a
> native PySide6 app. Primary source is the CAAC official site, with SearXNG / Bing as
> secondary sources. Out-of-region rules are filtered out automatically, and the Morning
> Brief lands every day.

**[⬇️ Download the installer (Releases)](https://github.com/Shifu-HU/uav-reg-watch/releases/latest)** ｜ [Architecture](docs/architecture.html) ｜ 简体中文：[README.zh-CN.md](README.zh-CN.md)

## ⚠️ Read this first: the summary is an index, the brief and the original are the conclusion

The one-line summary in the app is generated by a local small model. **It exists for fast
scanning only, it can differ from the source text, and it must never be used as a conclusion.**

1. Open **Morning Brief** in the sidebar and read the region / time window / source of every item, plus the "what to do" line;
2. Every entry ends with **View original →**, which opens the official announcement in your browser. **The original text always wins**;
3. For anything about no-fly zones, penalties or registration, **always verify against the original announcement and local rules**. Never make a flight decision based on the summary.

## 1. Two editions, each standalone

| | Mobile (recommended) | Desktop |
|---|---|---|
| Install | One APK, **no PC required** | `UAVRegWatch-Setup.exe` |
| Runtime | Ships a Python runtime and all business code inside the APK | Native PySide6 window |
| AI | **On-device llama.cpp + quantised Qwen2.5-0.5B** | Local Ollama (room for larger models, better summaries) |
| Network | Online only when fetching new rules; reading, filtering and AI all run offline | Same |
| Privacy | Everything stays on the device, nothing is uploaded | Same |
| Design | One shared theme token set (8 colour schemes × dark/light), zero drift | Same |

> The mobile APK is about 500 MB because **the runtime and the model are bundled** —
> in exchange it works fully offline right after install, with nothing else to download.

## 2. Install

### 2.1 Mobile (Android, recommended)

1. Download `UAVMobile.apk` from [Releases](https://github.com/Shifu-HU/uav-reg-watch/releases/latest) and install it;
2. First launch unpacks the model to local storage (~470 MB, **one-off**; allow about a minute — later launches are fast);
3. Pick your province / city in Settings, everything else is automatic — a bundled baseline of regulations means there is content from the very first open.

### 2.2 Desktop (Windows, optional)

1. Download `UAVRegWatch-Setup.exe` from [Releases](https://github.com/Shifu-HU/uav-reg-watch/releases/latest) and run it (installs to `%LOCALAPPDATA%\UAVRegWatchMine`, no admin rights needed);
2. Launch from the Start menu or the desktop shortcut. The installer ships a baseline database, so the app has content right away.

> To start over with clean data: delete the `data` folder and the app re-crawls everything (slow, one-off).

## 3. First-run setup

Both editions need exactly one thing from you: **the region**. Pick your province / city in
Settings and the geo filter works from there (keeps national + local + same-province rules).

Everything else has a sensible default:

| Setting | Default | Notes |
|---|---|---|
| Region | Shenzhen / Guangdong | **Change it to your city first** |
| Sources | CAAC site + Bing | SearXNG is off until you host one and enable it in config |
| AI model | Mobile: built-in Qwen2.5-0.5B; Desktop: `uav-reg` (falls back to `qwen3:4b` → `qwen3:8b`) | On desktop, `ollama pull qwen3:4b` is all you need |
| Theme | 8 colour schemes × dark/light | Every change saves itself, no save button |

## 4. Daily use

- **Today**: a top summary bar (new today / total / locally relevant) plus three blocks (Major / Watch closely / Older), each sorted Major → Important → Normal;
- **Morning Brief**: flight verdict banner on top (no-fly / caution / clear), then sections (temp no-fly / new today / watch / reference);
- **Favourites**: ★ star and 🚫 filter, consistent across both editions;
- **Daily delta**: newly published rules are searched automatically; today's new items are topped up from an unread backlog, without duplicates;
- The first Morning Brief takes about 40 seconds (includes a weather lookup); the app pre-warms it at startup, after which it opens instantly.

## 5. FAQ

| Symptom | Cause & fix |
|---|---|
| Summary disagrees with the original | Expected — the summary is only an index. Read the Morning Brief body, then "View original". For flight decisions the original is authoritative |
| First mobile launch is slow | The ~470 MB model is unpacked to local storage on first launch (one-off); allow about a minute, later launches are fast |
| Does it need to stay online? | No. Only fetching new rules needs the network; reading, filtering and AI all run on the device |
| How do the two editions relate? | Two standalone editions — either works on its own, sharing the same regulation logic and colour system |
| Does the mobile edition need a PC? | No. The runtime, the regulation baseline and the AI model are all inside the APK |
| CAAC site returns nothing | The site search only accepts POST (GET redirects to an anti-bot page) — the app handles this; an empty result usually means the site is down for maintenance |
| National rules get filtered as "out of region"? | They don't. The app strips the CAAC footer institution list before judging, and always keeps items with national markers |

## 6. Run from source

Skip the installer, or contribute:

```bash
git clone https://github.com/Shifu-HU/uav-reg-watch.git
cd uav-reg-watch
pip install -r requirements.txt

python -m uavwatch.cli doctor        # check environment
python -m uavwatch.cli bootstrap     # first full baseline (slow, one-off)
python -m uavwatch.tui               # desktop GUI
python -m uavwatch.cli daemon        # scheduled daemon (uses config schedule)
python -m uavwatch.cli brief         # generate today's brief manually
```

The mobile project lives in `src/android/` (Java shell + the on-device Python entry
`phone_server.py` + Qt compatibility shims). Building the APK requires cross-compiling
llama.cpp and bundling CPython — installing the APK from Releases is far easier.

Project layout:

```
uav-reg-watch/
├── src/uavwatch/          shared core for both editions
│   ├── config.py          config load/save
│   ├── storage.py         SQLite storage (WAL)
│   ├── geo.py             geographic filtering (core)
│   ├── fetcher.py         HTTP fetching (rate limit / encoding fallback)
│   ├── llm.py             local model analysis + rule fallback
│   ├── pipeline.py        fetch -> dedup -> analyse -> filter -> store
│   ├── morning.py         brief generation (Markdown / HTML / plain text)
│   ├── theme.py           theme tokens (single source of styling)
│   └── sources/           caac / searxng / bing / local
├── src/android/           mobile project (Java shell + phone_server.py + shim)
└── config.yaml            all desktop configuration
```
